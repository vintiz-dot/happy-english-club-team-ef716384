## 1. A2 - Teacher stability (opus implements, fable reviews) - DIAGNOSE BEFORE FIXING

### 1.1 What the code actually is (this changes the brief)

The "flipbook" is NOT an in-app page-turning viewer. `src/pages/TeacherBooks.tsx:533-539` renders one `<iframe src={activeBook.url}>` pointing at a third-party embed (Google Slides, Canva, YouTube, a flipbook host; `cleanAndSuggestUrl` at :99-156). There is no per-page render, no page image and no page-flip library in the repo (package.json has none). So four of the brief's hypotheses are refuted by reading, and the real candidates are about the iframe being DESTROYED AND RELOADED, and about overlays in fullscreen.

| # | Hypothesis | Evidence in code | Status before measuring |
|---|---|---|---|
| H1 | **Token refresh / tab refocus destroys the book.** The loader effect depends on `[user, toast]` (`TeacherBooks.tsx:172-228`) and calls `setLoading(true)` (:176). While loading, the page returns a different tree (spinner, :411-420), so the iframe unmounts. `useAuth.tsx:60-64` writes `user: session?.user` on EVERY auth event that is not SIGNED_OUT, including `TOKEN_REFRESHED` (about hourly) and the `SIGNED_IN` supabase-js emits when a tab regains focus; that is a new object each time.
